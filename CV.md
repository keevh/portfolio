## Proyectos destacados

### LUMEN — Demo de e-commerce con panel administrativo

Proyecto personal desarrollado con Next.js, React, TypeScript, Tailwind CSS e IndexedDB. Construí una experiencia de comercio electrónico en español que incluye catálogo, detalle de producto, carrito, checkout y un panel administrativo para gestionar productos, precios, descuentos, pedidos y configuración de tienda. El objetivo fue simular un flujo end to end sin depender de un backend real, manteniendo consistencia entre la vista pública y el backoffice mediante un modelo de datos local persistente. Este proyecto demuestra criterio de producto, organización de interfaces complejas, manejo de estado y modelado de reglas de negocio en una aplicación web moderna.

### Trimly — Acortador de URLs con analítica

Proyecto full stack desarrollado con TypeScript, React, Node.js, Redis y enfoque en analítica. Diseñé una herramienta para transformar enlaces largos en URLs cortas, con una interfaz minimalista y un flujo orientado a la rapidez de uso. La solución contempla un motor de redirección de baja latencia apoyado en caché, junto con recolección asíncrona de telemetría para medir clics sin afectar el rendimiento percibido por el usuario. El proyecto me permitió trabajar decisiones de arquitectura, separación entre camino crítico y tareas secundarias, y diseño de un producto SaaS liviano con valor práctico.

### Portafolio personal — Sitio web estático con contenido bilingüe

Sitio personal desarrollado con Astro, React, TypeScript, Tailwind CSS y arquitectura de islands. Implementé una estructura de contenido para proyectos, experiencia y secciones del portafolio, con soporte bilingüe mediante estado global reactivo y despliegue en GitHub Pages. El proyecto está pensado para presentar casos de estudio de forma clara, mantener buen rendimiento y facilitar la actualización de contenido sin modificar la lógica principal de la aplicación.

### Proyectos de fundamentos frontend e interacción

Además de los proyectos principales, he desarrollado ejercicios interactivos en JavaScript vanilla, HTML5 Canvas, Local Storage y MockAPI para reforzar fundamentos de lógica, eventos, renderizado, persistencia en navegador y soporte móvil.
