# Kevin Gallardo — Portfolio

Portfolio personal de desarrollador Full Stack. Construido con React, TypeScript y Tailwind CSS v4.

## Stack

- **React 19** + **TypeScript**
- **Tailwind CSS v4**
- **Motion** (animaciones)
- **Vite**

## Desarrollo local

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
pnpm preview
```
